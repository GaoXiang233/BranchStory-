## 项目概述

分支故事是一个基于阿里云ESA的边缘原生多分支互动小说系统，利用边缘计算和AI技术为用户提供低延迟、智能化的多分支互动叙事体验。用户的选择将直接影响故事走向，AI实时生成新的情节和选项，实现真正的个性化互动叙事。

项目现已完成核心功能开发，包括智能故事生成、多分支选择系统、边缘状态管理、故事合成器、故事编辑器等，并已部署上线供用户使用。最新版本增加了用户自定义故事的完整支持，允许用户创作并运行自己的互动故事。

## 项目特性

### 1. 边缘原生设计
- **低延迟体验**：充分利用阿里云ESA全球边缘节点，将计算和数据存储部署在离用户最近的位置
- **动态加速**：通过智能路由选择最优边缘节点，确保最佳访问体验
- **就近部署**：边缘函数和KV存储就近部署，减少网络往返时间

### 2. 智能叙事引擎
- **AI实时生成**：集成通义千问API，根据用户选择实时生成个性化故事情节
- **上下文理解**：AI理解完整故事上下文，生成连贯、合理的后续情节
- **多模态支持**：支持文字、符号、情感等多种叙事元素

### 3. 多分支互动体验
- **选择驱动**：每个选择都影响故事走向，实现真正的分支叙事
- **智能选项**：AI根据当前情境生成有意义、有影响力的选项
- **个性化路径**：用户路径独一无二，每次体验都不同

### 4. 实时状态管理
- **边缘KV存储**：用户状态数据就近存储在边缘节点
- **状态同步**：实时同步用户状态，支持跨设备访问
- **持久化存储**：用户进度自动保存，支持断点续读

### 5. 智能缓存优化
- **多级缓存**：基于语义相似度的多级缓存机制
- **预测预载**：基于用户行为预测预加载可能的分支内容
- **智能失效**：基于内容变化和用户行为的智能缓存失效机制

### 4. 故事合成器
- **完整小说生成**：将用户的选择历程整合成连贯的中短篇小说
- **个性化输出**：根据用户的具体经历生成定制化故事
- **高质量内容**：利用AI将片段自然过渡成完整故事
- **双格式导出**：支持导出为Markdown或纯文本格式

### 5. 用户体验优化
- **自定义故事**：用户可以设置故事类型、标题和背景，生成个性化内容
- **流畅过渡**：点击选项后立即显示"正在生成故事..."，避免界面无响应
- **清晰时间线**：优化时间线显示，只显示"第X幕"标题，避免重复
- **无缝返回**：添加"返回主页"按钮，方便用户随时回到主界面
- **响应式加载**：提供清晰的加载反馈，提升等待体验

### 6. 故事编辑器功能
- **多故事管理**：支持创建、重命名和删除多个独立的故事
- **节点编辑**：可视化编辑故事节点，支持内容和选项配置
- **智能链接**：通过下拉选择器直观地连接不同故事节点
- **数据持久化**：自动保存故事数据，支持手动保存和恢复
- **本地存储**：所有创作内容保存在本地，保护用户数据
- **节点选择器**：从现有节点列表中选择目标节点，简化连接操作
- **灵活选项**：选项文本内容可在未连接目标节点时保存，支持后续连接
- **实时预览**：提供"预览故事"按钮，即时测试自定义故事
- **混合叙事**：支持预设节点跳转与AI生成内容相结合的叙事模式

### 7. 用户创作支持
- **自定义故事创作**：用户可在内置编辑器中创建原创故事节点
- **混合叙事模式**：支持预设节点与AI生成内容相结合
- **灵活选项处理**：选项文本可保存后连接，也可触发AI生成新内容
- **实时预览功能**：即时测试用户创建的故事流程
- **智能跳转系统**：有连接的选项跳转预设节点，无连接的触发AI生成

### 8. 故事复盘功能
- **路径追踪**：完整记录用户的故事选择路径
- **选项对比**：显示每步可选内容及用户实际选择
- **过程分析**：帮助用户理解故事发展脉络
- **创作借鉴**：为后续故事创作提供参考依据
- **自定义标题**：支持用户自定义复盘文件标题
- **双格式导出**：支持导出为Markdown或纯文本格式
- **便捷导出**：一键导出完整的故事历程
- **灵活选项**：选项文本内容可在未连接目标节点时保存，支持后续连接
- **实时预览**：提供"预览故事"按钮，即时测试自定义故事
- **混合叙事**：支持预设节点跳转与AI生成内容相结合的叙事模式

## 技术架构

### 前端架构
- **UI框架**：React 18 with Concurrent Features
- **类型安全**：TypeScript with strict mode
- **构建工具**：Vite for fast HMR
- **状态管理**：Zustand for lightweight state management
- **路由管理**：React Router v6
- **样式方案**：CSS Modules + Tailwind CSS patterns

### 边缘架构
- **边缘平台**：阿里云ESA（Edge Security Accelerator）
- **部署方案**：ESA Pages + 边缘函数 + 边缘KV存储
- **函数计算**：边缘函数处理AI请求、状态管理
- **数据存储**：边缘KV存储用户状态、缓存数据
- **加速网络**：全球CDN网络，智能路由

### AI集成
- **模型选择**：通义千问qwen-plus
- **API接口**：DashScope API
- **提示优化**：针对互动叙事优化的提示词工程
- **格式统一**：标准化的输入输出格式

## 快速开始

### 环境准备
```bash
# 确保已安装 Node.js 16+ 和 npm
node --version
npm --version
```

### 项目启动
```bash
# 1. 克隆项目
git clone [仓库地址]
cd BranchStory

# 2. 安装依赖
npm install

# 3. 配置API密钥（开发环境）
# 创建 .env 文件
echo "VITE_QWEN_API_KEY=your_api_key_here" > .env
echo "VITE_QWEN_MODEL=qwen-plus" >> .env

# 4. 启动开发服务器
npm run dev

# 5. 构建生产版本
npm run build
```

### API密钥配置
1. 访问[阿里云DashScope控制台](https://dashscope.console.aliyun.com/apiKey)
2. 创建API密钥
3. 将密钥填入 `.env` 文件中的 `VITE_QWEN_API_KEY`
4. 选择模型（可选，默认为qwen-plus）
